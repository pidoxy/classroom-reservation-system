# Implementations

The contract is language-free, so many implementations can live side by side. This is the index.

| Language | Where | Author | Steps passing | Notes |
| --- | --- | --- | --- | --- |
| Python | [`implementations/python`](../implementations/python) | Starter | 0 | Connection check only |
| JavaScript | [`implementations/javascript`](../implementations/javascript) | Starter | 0 | Connection check only |

## Adding yours

Keep your work in your own fork. When a step passes, open a pull request that adds one row above, linking to your fork, with the output of the check as evidence. See [CONTRIBUTING.md](../CONTRIBUTING.md).

Want a language that is not here (Go, Java, C#, Rust, Ruby, PHP)? Use the [new language starter](../.github/ISSUE_TEMPLATE/new-language-starter.md) issue.
